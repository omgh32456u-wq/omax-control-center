# Omax Control Center

A lightweight, mobile-first admin dashboard for managing activation codes and subscriptions.

## Planned stack
- React + TypeScript + Vite
- Capacitor for Android APK
- Supabase Auth, Postgres, RLS and Edge Functions
- Vercel for web hosting

## Security
Never commit Supabase service-role keys or other server secrets. All privileged operations must be performed by authenticated, server-side functions with explicit admin authorization.
